# ZenPlayer 产品迭代 PRD

*连续播放 · 可靠续听 · 快速找课*

文档版本 1.0  |  2026-09-26  |  产品需求与验收基线

> 找到想听的课，安心连续听；下次打开，仍然记得听到哪里。

### 01 / 版本摘要

本轮只补齐三条核心体验链路：本次收听不中断、下次回来接着听、明确目标快速找。保留现有讲座浏览、音视频切换、下载、降噪与音量增强，不做整体视觉重设计。

| 优先级 / 需求组 | 本版交付 | 用户价值 |
| --- | --- | --- |
| 1 · 连续播放 F1 | 全局播放会话、迷你播放器、系列顺序连播、播完本集停止 | 返回不打断；每集不必重新操作 |
| 2 · 可靠续听 F2 | 首页一键续听、长期进度、单集状态、旧数据迁移 | 少找一次；进度不会被最近列表挤掉 |
| 3 · 快速找课 F3 | 当前分类搜索、当前系列搜索、按集数定位、简繁匹配 | 减少层级浏览和长距离滚动 |

### 02 / 交付约束

目标平台：现有 iPhone 与 macOS；维持当前部署版本约束。文档用简体中文，新增应用文案使用繁体中文。PRD 版本号不等于 App 发布版本号。

需求状态：三项产品方向已获采纳；下文默认值、边界与性能目标为本稿提出的可执行方案，不代表已经过用户测试或实机验证。开发前发现与真实数据冲突时，以变更记录说明，不静默改口径。

源码基线：JiongXing/ZenPlayer，main @ a86d74a4b35d7aea330be48480727d8652210914。本次核对仍为该提交；仅代表此基线，不代表其他分支或本地未提交修改。[^S1]

> 非目标：账号 / 云同步、全站搜索、AI 推荐、收藏与笔记、倍速与睡眠定时、批量下载、复杂自定义队列。不得把它们作为本版前置依赖。

## 01  现状、范围与核心路径

*先复用现有能力，再补齐缺口*

| 源码事实 | 产品缺口 / 对策 |
| --- | --- |
| 播放页持有播放器；前台离开页面时停止并释放。[^S2][^S3] | 会话移出页面；导航返回只收起界面。 |
| 单集结束只标记完成，播放上下文没有系列队列。[^S3] | 补充系列上下文与顺序连播规则。 |
| 已有位置保存和恢复；最近记录最多 10 条，进度同存同删。[^S3][^S4] | 不重做断点续播；将长期进度与最近展示分离。 |
| 首页主要是分类；最近播放在“我的”内。[^S5] | 首页独立展示本地续听入口，不受分类加载失败阻塞。 |
| 分类有排序，系列展示单集；客户端无搜索封装。[^S6][^S7] | 先做当前已加载列表的确定性搜索与定位。 |

### 核心路径与成功结果

场景 A · 连续听：从系列第 N 集开始 → 返回浏览其他页面 → 声音继续 → 本集播完进入实际列表下一集。用户可主动暂停或设置本集结束停止。

场景 B · 隔天听：冷启动 → 首页看到上次未完成内容 → 点一次“繼續收聽” → 恢复位置；启动本身不自动出声。

场景 C · 定向找：进入分类输入课程标题 / 编号 → 进入系列 → 输入集数定位 → 用户确认点击播放。定位操作本身不改变当前播放。

### 导航与页面职责

保留“首頁 / 我的”。首页增加续听卡；分类页增加搜索；系列页增加搜索、集数定位、上次位置与进度标识；完整播放页增加当前单集信息、上一集 / 下一集及连播开关。

迷你播放器位于应用内容安全区底部：根页在 Tab 上方，详情页在窗口底部；完整播放页 / 视频全屏不重复显示。所有入口控制同一会话，不再通过新建播放页创建新播放器。

术语：课程 / 系列 = SeriesItem；单集 = EpisodeItem；播放会话 = 当前媒体、位置、队列与播放意图；队列 = 系列完整已加载列表的顺序快照。

## 02  F1 · 全局播放会话

*离开界面，不等于结束收听*

### F1-01 · 单一会话与导航

App 进程内只允许一个活动播放会话。返回、切换 Tab、打开分类、浏览另一课程、打开或关闭完整播放界面，不得停止、重建或重置当前媒体。重复点击同一单集仅打开控制页；暂停状态不因打开页面而自动恢复。

点击另一单集属于明确换课意图：先保存旧位置，再切换新内容；不弹二次确认。快速连续点击时只接受最后一次选择，过期异步回调不得覆盖当前单集、进度或锁屏标题。

### F1-02 · 迷你播放器

显示课程 / 单集名、集数、播放或加载状态；主按钮播放 / 暂停，点击信息区打开完整播放页。标题过长截断显示但提供完整可访问名称。“更多”中提供“停止播放”。无会话时隐藏，暂停时保留；失败时显示可重试状态。

### F1-03 · 行为与状态

| 动作 / 事件 | 规定行为 |
| --- | --- |
| 返回、切 Tab、收起播放页 | 保持位置与播放意图；视频可继续音频，不能另建音频会话。 |
| 用户暂停 / 耳机断开 | 保存位置，进入暂停；未获新播放指令不自行恢复。 |
| 用户选择“停止播放” | 保存位置，结束会话并移除迷你条、释放媒体控制；不删除收听历史。 |
| 冷启动 / App 被终止后重开 | 展示续听卡，不自动播放；不依赖终止回调才能保住进度。 |
| 系统音频中断结束 | 仅在中断前播放、系统允许恢复且期间未手动暂停时恢复。 |
| 播放自然结束 | 交给队列规则；若无下一集或连播关闭，停在“已播完”，不循环。 |

### F1-04 · 控制一致性

完整页、迷你条与 iOS 锁屏的标题、播放 / 暂停、当前位置必须一致。音视频切换保留切换当下的有效位置和播放意图；不能只读上一个周期的旧进度。切换失败不写入 0，保留可恢复的旧位置并提供重试。

验收关联：AT-01～AT-06、AT-11、AT-12。

## 03  F1 · 系列顺序连播

*按完整列表继续，不按搜索结果跳集*

### F1-05 · 队列来源与顺序

从系列内任意单集开播时，携带该系列全部已加载单集、当前索引及系列元信息。顺序与未筛选的系列列表一致；搜索只改变可见结果，不改变队列。集数 1、2、5 表示 2 后播 5，不猜测或请求不存在的第 3 集。

从首页、最近播放或已下载进入：优先恢复保存的系列快照；缺少系列上下文时按单集播放，提示“暫無系列清單，僅播放本集”。不能为了补齐队列阻塞已可播放的当前集。若远端列表未完整加载，队列仅覆盖已加载内容，并明确这一范围。

### F1-06 · 连播设置与前后切换

开关文案“播完自動播放下一集”，首次默认开启，偏好在本设备记忆。关闭表示当前集播完停止，不立即暂停；不扩展为倒计时功能。完整播放页提供上一集 / 下一集，边界禁用；手动切集属于新的播放指令，成功后开始播放。

下一集位置：未完成则恢复该集保存位置；无进度从 0 开始；已完成也从 0 开始，不自动跳过已听集。自动切集只有在当前有效媒体自然结束且连播开启时发生；拖动进度、缓冲、返回、失败不得误触发。

### F1-07 · 媒体选择与失败边界

| 情形 | 处理规则 |
| --- | --- |
| 下一集支持当前音 / 视频类型 | 保持类型，继续沿用“该类型本地优先、远端回退”。 |
| 缺少当前类型、只有其他可播类型 | 切换到可用类型并提示；不把缺视频的正常音频课当作错误。 |
| 离线且所选类型无本地文件 | 若另一类型已下载，使用本地类型并提示；否则暂停等待用户处理。 |
| 下一集无源、损坏、加载失败 | 保留上一集完成状态与队列，显示失败目标；仅手动重试 / 跳过，不静默跳课。 |
| 最后一集结束 | 停播；保留已完成状态，可主动重听。不得自动回第一集。 |
| 新课程准备失败 | 旧进度不丢、不静默恢复旧音频；失败目标可重试，用户可主动返回旧内容。 |

同一结束通知只能推进一次。切集期间沿用用户降噪与音量增强设置；不得因会话重构悄悄重置偏好。[^S3]

验收关联：AT-07～AT-10、AT-12。

## 04  F2 · 首页一键续听

*首屏给出下一步，而不是让用户重走目录*

### F2-01 · 首页续听卡

续听卡由本地记录驱动，放在分类区域之前，独立处理加载与错误。分类接口失败或无网络，不得遮住续听卡；已下载的目标仍能直接播放。卡片展示课程名、单集标题 / 集数、有效位置和主操作；无可靠总时长时只显示“已聽 mm:ss”，不编造百分比。

| 候选优先级 | 卡片内容与主操作 |
| --- | --- |
| 1 · 当前活动会话 | 播放中显示“正在收聽”及暂停；暂停时“繼續收聽”；准备中展示状态并禁止重复发起。 |
| 2 · 最近实际收听的单集未完成 | 显示已听位置；点击恢复位置并开始播放。 |
| 3 · 最近单集已完成，紧邻下一集明确且未完成 | 显示“繼續下一集”；按下一集自身进度播放，不显示上一集的 100%。 |
| 4 · 其他未完成记录 | 选最近一条有实际收听进度的记录，仍用明确的课程名和集数。 |
| 5 · 无可续听内容 | 不显示续听卡；分类正常展示。不能以最近一次失败的开课替代真实记录。 |

活动会话在此指准备、播放、缓冲或暂停，不含已结束 / 已停止；失败状态保留在迷你条。冷启动不主动还原活动播放，只使用持久化记录生成入口。卡片一次点击完成续听；不用先进入历史列表，也不要求重新选择音视频。

### F2-02 · 系列内的进度可见性

单集行显示“未收聽 / 已聽 mm:ss / 已聽完”；视觉标记不替代文字。系列页有该系列历史时提供“定位上次收聽”，滚动到最近实际收听集并高亮，不自动播放。已完成单集可点按重听，重听从 0 开始。

首页续听、历史条目和下载条目一旦带有系列信息，进入播放器时继续传递，避免续听入口变成只能播单集的孤岛。旧记录缺少该信息时只降级队列，不丢弃进度。

### F2-03 · 最近播放的职责

最近页面继续展示最多 10 条；底层按所有长期记录的最后实际收听时间生成。仅预加载、打开详情或播放失败不刷新“最近”。最近条目被挤出只影响展示，绝不能移除长期进度。[^S4]

验收关联：AT-13～AT-16、AT-18、AT-19。

## 05  F2 · 进度可靠性与迁移

*显示范围有限，收听记忆不按条数淘汰*

### F2-04 · 保存与恢复规则

长期保存每集的当前位置、状态、最后实际收听时间及可恢复的媒体 / 系列上下文。正常运行且存储可写时，播放期间至少每 5 秒落盘；暂停、有效拖动完成、切集、停止、前后台切换时立即保存。异常终止只能恢复最后成功落盘的位置，不承诺必有终止回调。

准备与恢复过程中禁止把初始 0 写回已有位置。新的实际播放尚未成功开始时，不覆盖旧历史。进度必须是有限非负数；总时长以当前有效媒体提供的可信时长优先，元数据为回退。音视频切换先抓取当前时间，再切源与恢复。

完成状态以当前有效媒体的播放结束事件为准，不以“超过 95%”推断。时长未知也可以记录完成标志；仅拖到接近结尾不算完成。已完成单集重听时，首次实际播放推进后改为未完成状态并从新进度记录；首次未启动成功不能清除完成标志。

### F2-05 · 存储与清理边界

长期进度与最近 10 条展示拆分；不设置按数量或时间自动淘汰。删除下载文件、切换音视频、更新列表、清空搜索，都不得删除对应进度。本版不提供“清空收听记录”功能，也不承诺卸载后或跨设备恢复。

持久化写入应可恢复：新数据成功写入前不得删除旧数据；单条损坏不清空全部记录。保存失败保留内存状态及原文件，给出“進度暫未儲存，請檢查可用空間”的非阻断提示，后续恢复可写时重试。

### F2-06 · 旧版迁移

| 阶段 | 要求 |
| --- | --- |
| 读取与映射 | 读取旧 recentPlayback.records，保留原识别键及位置；旧时长已知且位置到终点时标记完成。缺少新字段可空缺。 |
| 写入与校验 | 先写新版本结构，校验有效记录数量、识别键、位置与完成状态；成功后写迁移完成标志。 |
| 幂等与失败恢复 | 迁移重入不能重复、不能覆盖较新的进度；失败继续保留旧记录并允许重试，不阻断普通浏览。 |
| 兼容与事实边界 | 保留原记录备份用于故障恢复；不保证自动兼容旧版 App 降级。旧版已淘汰的进度无法凭空补回。[^S4] |

验收关联：AT-16～AT-21。

## 06  F3 · 课程搜索与集数直达

*只承诺真实覆盖的搜索范围*

### F3-01 · 当前分类找课程

分类页增加搜索框“搜尋本分類課程或編號”，在已加载 SeriesItem.title / num 上匹配，结果保留名称、编号、日期及现有区分信息。沿用当前用户选择的排序；清空后恢复完整列表和排序。结果文字为“找到 N 門課程”，不是全站搜索。[^S6][^S8]

### F3-02 · 当前系列找单集

系列页增加“搜尋本系列標題或集數”，匹配 EpisodeItem.title / num / episode。纯数字查询优先排列集数字段精确匹配项，其余命中仍保留完整列表中的相对顺序。点击结果才播放；即使只显示一集，开播时仍传递未筛选的完整已加载队列。[^S9]

### 匹配统一规则

首版采用本地确定性包含匹配：去首尾空格，忽略大小写，统一全角 / 半角和简繁检索形式；多词以空白分隔时，每个词都需在可搜索字段之一命中。原始标题保持原样，不把归一化结果展示给用户。不做拼音、语音、语义或自动纠错搜索。

简繁验收至少覆盖“无量寿经 / 無量壽經”“净土 / 淨土”。一对多字词转换使用固定、可测试的规则，接受首版词典覆盖边界，不宣称所有异体字均等价。

### F3-03 · 按集数定位

系列页提供“跳至集數”。接受 12、0012、全角数字及“第12集”等明确阿拉伯集数形式，按实际 episode 字段精确匹配，不按数组下标匹配。拒绝负数、小数与无法识别输入；合法但不存在时提示“找不到此集，請確認集數”，不就近猜测。

提交后收起输入面板，清除当前单集搜索筛选，滚动并高亮目标约 2 秒；不改变播放或队列。若同一集数有多个条目，展示候选供选择。支持第 0 集前提是数据中确有该条目。“定位上次收聽”沿用同样的清筛选 / 高亮规则。

### F3-04 · 加载、空结果与离线

搜索只作用于已加载数据。rows 少于 total / totalCount 时明确“僅搜尋已載入內容”，不显示“全部搜索无结果”。无结果可一键清除关键词；加载失败提供重试，不能混同为零命中。没有缓存且离线时说明需联网；不新增全量目录抓取或目录离线缓存。[^S8][^S9]

验收关联：AT-22～AT-26。

## 07  共通体验、平台与质量

*不以新功能换取旧能力回退*

### Q-01 · 跨平台边界

| 平台 / 场景 | 必须满足 |
| --- | --- |
| iPhone | 前台跨页播放、后台音频、现有锁屏控制、耳机断开与系统中断规则均保持；PiP / 全屏共用同一播放器，不因视图消失停播。 |
| macOS | 窗口内跨页与窗口失焦不停止；若存在多个应用窗口则共享唯一会话；退出 App 后停止并保存。首版不新增 macOS 锁屏控制能力。 |
| 现有宽屏布局 | 不要求重构导航；迷你条不遮住列表末行、底部按钮或系统安全区。 |
| 下载与媒体处理 | 保留已有下载 / 删除 / 分享、音视频切换及本地优先；降噪处理失败仍回退可播放原声，不重写算法。[^S3][^S10] |

### Q-02 · 加载与错误反馈

所有播放入口应立即反馈选择；准备耗时超过 300 毫秒显示加载态。加载中可退出界面，不能因再次点击重复建会话。检测到网络 / 媒体错误立即展示；持续 30 秒无有效准备或缓冲进展则进入可重试状态，暂停计时不算卡顿。此为体验超时策略，不是远端性能承诺。

重试保留目标单集、最后有效位置、媒体偏好与队列。旧媒体迟到的成功或失败回调不影响当前会话。播放失败不弹层层错误；在迷你条与完整页展示同一状态、同一重试动作。

### Q-03 · 可访问性与布局

新增文案统一繁体；搜索输入兼容简繁。iPhone 主操作触控区域目标不小于 44 × 44 pt；下载行与播放行的点击区域不得互相误触。支持现有动态字体、明暗模式与 macOS 键盘焦点；状态不单靠颜色区分。缩短动画偏好下用静态标记替代滚动 / 闪烁强调。

### Q-04 · 性能验收口径

本地列表搜索在测试数据已加载后，输入稳定到结果更新的 P95 目标不超过 200 毫秒（如含防抖，需计入）；样本为 1,000 门课程或 2,000 集。操作反馈目标不超过 100 毫秒。以上是建议验收目标，先记录参考真机与实测，不代表现状已达标。

不能为搜索遍历所有分类接口；队列快照不随每个进度 tick 全量重写。进度增量更新不得引起长列表整页抖动或滚动位置丢失。

## 08  数据与集成约束

*描述责任边界，不限定具体持久化框架*

### 建议的逻辑对象

| 对象 | 最少信息 / 职责 |
| --- | --- |
| PlaybackSession | 唯一当前单集、媒体类型、有效时间、播放意图、阶段、错误、请求版本；负责媒体资源与系统命令。 |
| QueueSnapshot | 系列标识 / 标题 / 详情地址、已加载单集顺序、服务器地址、当前索引、完整性标记、快照版本。 |
| PlaybackProgress | 单集识别键、当前位置、可信时长、未开始 / 未完成 / 已完成、最后实际收听时间、媒体偏好、可选系列关联。 |
| Recent / Resume 查询 | 基于长期进度派生最近 10 条与首页候选，不再拥有独立淘汰进度的权力。 |
| SearchState | 当前页面关键词、排序及定位目标；不写入播放队列，不持久化敏感查询原文。 |

### D-01 · 识别与兼容

首版进度沿用旧键 episode.id + serverUrl 的对应关系；迁移保留原始键，不擅自修改 URL 字符串导致旧记录失联。[^S4] 系列关联新增 seriesId、seriesTitle、seriesDetailURL 与快照引用。新字段允许缺失，不能为补齐字段舍弃历史。

开发需验证代表性数据的单集键是否跨系列唯一；若不唯一，保留 legacyKey 并显式映射，不能只用集数或标题去重。服务器迁移导致身份变更时，需单独设计映射，本版不靠相似标题自动合并记录。

### D-02 · 并发与原子性

所有播放入口进入同一入口方法；选择递增的请求版本，只有当前版本可提交状态。恢复位置和播放准备完成前保护旧进度；结束事件同时验证媒体身份与队列版本，防止重复推进。删除下载或数据刷新不能改变正在播放条目的身份。

### 现有模块改动范围

ContentView：注入共享会话、承载迷你条。PlayerView / PlayerViewModel：分离页面与会话生命周期。SeriesDetailView / EpisodeRowView：传递完整队列、展示进度、搜索定位。HomeView：本地续听区域独立渲染。RecentPlaybackStore：迁移与职责拆分。[^S2]～[^S6]

> 技术方案可选择本地文件、数据库或其他可测试存储，但必须实现本稿迁移与持久化约束。不引入新后端；不把“删掉 onDisappear 停止调用”当成全局播放器的完整实现。

## 09  验收用例 A · 连续播放

*可观察结果优先；通过条件不可只看界面*

测试准备：至少一套音频系列、一套音视频混合系列；含集数 1 / 2 / 5、无源条目、时长未知条目；准备本地已下载和远端媒体。真机验证 iPhone 后台 / 锁屏 / PiP，macOS 验证实际窗口生命周期。以下均为本版必验。

| ID | 操作 / 条件 | 通过标准 |
| --- | --- | --- |
| AT-01 | 播放中返回、切 Tab、浏览其他课程，再打开完整页 | 声音不中断、位置连续；无第二播放器、无重复加载。 |
| AT-02 | 暂停后收起 / 打开完整页；重复点同一单集 | 保持暂停和原位置；不因视图出现自动 play。 |
| AT-03 | 迷你条 / 完整页 / iOS 锁屏交替控制 | 播放状态、当前标题、位置保持一致，命令只执行一次。 |
| AT-04 | 迷你条选择“停止播放”并重新冷启动 | 会话与锁屏信息清理；首页仍能续听；启动不出声。 |
| AT-05 | A 播放时依次快速点 B、C，令 B 的请求最后返回 | 最终只显示 / 播放 C；A 进度保存，B 不覆盖状态。 |
| AT-06 | 播放中拔耳机、来电中断；期间手动暂停 | 拔耳机暂停；手动暂停后不被中断结束自动唤醒。 |
| AT-07 | 开启连播，第 2 集结束；队列为 1 / 2 / 5 | 进入第 5 集；沿用设置，只推进一次，不请求第 3 集。 |
| AT-08 | 关闭连播；或队列最后一集播放结束 | 停在已完成；不立即循环、不自动继续。重开后偏好仍在。 |
| AT-09 | 只搜出第 2 集后点击播放，令其结束 | 按未筛选队列进入下一集，不把搜索结果当完整队列。 |
| AT-10 | 下一集类型缺失 / 离线 / 加载失败 | 按 F1-07 明确切类型或暂停；不静默跳课，不丢上一集完成态。 |
| AT-11 | 音频播到中途暂停后切视频；再模拟切换失败 | 成功切换保留当下位置与暂停意图；失败不写入 0。 |
| AT-12 | iPhone 锁屏自动换集、PiP / 全屏往返；Mac 切页与失焦 | 同一会话持续、切集信息更新；退出 App 停止，无重复音轨。 |

补充边界：无队列旧历史仅播放本集；列表未完整加载时不把已加载末尾标作整套课程完成。自动切集遇到新媒体失败必须可手动重试。

## 10  验收用例 B · 续听与搜索

*覆盖升级后、离线时和失败后的真实路径*

| ID | 操作 / 条件 | 通过标准 |
| --- | --- | --- |
| AT-13 | 有未完成记录，冷启动后点首页续听 | 一次点击恢复有效位置并播放；无需历史中转。 |
| AT-14 | 分类 API 失败，续听目标已下载 | 首页仍显示续听卡，可离线开播；分类错误独立显示。 |
| AT-15 | 最近一集已完成，存在明确未完成下一集；再测无候选 | 卡片指向下一集自身进度；无候选不显示误导性续听卡。 |
| AT-16 | 依次播放 30 个单集后回到第 1 个，重开 App | 最近只显示 10 条；第 1 集原进度仍可恢复。 |
| AT-17 | 拖动完成、暂停、切集、强制终止再打开 | 动作后保存；异常终止恢复最后成功落盘值，不被初始 0 覆盖。 |
| AT-18 | 未知时长播完；已完成内容重听；只拖到近末尾 | 结束状态可保存；实际重听后更新进度；近末尾不误判完成。 |
| AT-19 | 系列搜索后点“定位上次收聽”；删除下载 | 清筛选并定位，不开播；删除文件不删除收听状态。 |
| AT-20 | 迁移正常 / 缺字段 / 重复迁移 / 写入失败数据 | 有效旧进度保留，不重复、不覆盖新值；失败保留旧备份。 |
| AT-21 | 损坏一条记录或模拟空间不足 | 其他记录可读；失败写入不清空存储，提示与重试有效。 |
| AT-22 | 分类输入标题 / 编号，再清空查询 | 仅匹配当前分类，原排序保持；清空恢复完整列表。 |
| AT-23 | 简繁、全半角、多词；episode 数值精确匹配 | 按 F3 匹配规则一致，原标题不变；数字精确项优先。 |
| AT-24 | 输入 12 / 0012 / 第12集，且目标被搜索隐藏 | 清筛选、滚动高亮正确条目；不按下标、不自动播放。 |
| AT-25 | 不存在集数、重复集数、非法输入、零搜索结果 | 分别提示或给候选；不猜测 / 不跳错；零结果可清查询。 |
| AT-26 | 部分加载、首次离线、性能样本、字体与键盘检查 | 明确搜索范围与失败；达参考机目标；不遮挡、可操作。 |

回归必验：原分类排序、单集播放与音视频地址兜底、下载 / 暂停 / 恢复 / 删除、文件分享、降噪及音量增强。测试报告需标明设备、系统版本、构建号与使用的媒体样本。

## 11  验证指标与开发交付

*先测基线，不编造提升比例或上线日期*

### 观察指标与定义

| 指标 | 口径与目标方向 |
| --- | --- |
| 返回中断率 | 播放中发生应用内导航后，非用户意图停播的次数 / 对应导航次数；验收脚本中目标为 0。 |
| 续听成功率 | 有有效保存记录且目标媒体可用时，续听成功并恢复正确位置 / 续听尝试；自动验收用例全部通过。 |
| 连播成功率 | 开启连播、存在可用下一集并自然结束时，成功进入下一集 / 符合条件次数；单独记录网络 / 媒体失败。 |
| 找课耗时 | 用户明确要找什么后，从进入查找流程到成功播放的耗时；与相同题目的旧版任务测试比较。 |
| 数据完整性 | 迁移前后有效记录数、键与进度核对；测试数据无丢失、无重复，最近条数不影响长期数据。 |

本项目尚未提供行为数据，因此不承诺留存、时长或转化的提升百分比。先以验收脚本和小范围可用性测试验证；网络失败不从报告中消失，而与可控流程错误分开统计。

### 隐私约束

本版不引入远端行为埋点作为发布依赖。测试可记录本地匿名事件类型、耗时、成功 / 失败分类；不上传课程标题、查询原文、媒体 URL、具体收听轨迹或可识别用户的内容标识。未来增加分析服务需另行明确告知、权限与数据最小化方案。

### 建议的开发拆分（不是工期承诺）

| 阶段 | 交付与依赖 |
| --- | --- |
| M0 · 先保住进度 | 拆分长期进度与最近展示、幂等迁移、单元测试；此修复可先独立交付。 |
| M1 · 统一会话 | 单一播放服务、全入口路由、迷你条与系统控制一致性；不得只删视图停止逻辑。 |
| M2 · 系列连播 | 系列快照、切集设置、源回退与失败恢复；依赖 M1，复用 M0 进度。 |
| M3 · 首页与系列续听 | 本地独立续听卡、状态展示、上次定位；依赖 M0 / M1，队列与 M2 集成。 |
| M4 · 搜索与总验收 | 页内匹配、集数直达可并行；最终按全量 AT 用例验证，不改变 M2 队列。 |

## 12  发布门槛、默认决策与依据

*三条方向确认；以下细节作为本稿开发默认值*

### 发布门槛

AT-01～AT-26 全部通过，并完成原功能回归。至少补充进度迁移 / 恢复、队列边界与防重复、搜索归一化单元测试；iPhone 后台 / PiP 和 macOS 生命周期使用真机验证。本文未执行这些测试。

不能有数据丢失、重复播放、退到首页停播、错误跨集或进度清零等阻断问题。发现持久化缺陷先停发，保留新旧数据并做前向修复，不直接降级造成数据覆盖。媒体与模型身份验证不通过时，修订映射方案后再迁移。

### 默认决策与尚待工程验证项

连播默认开启并记忆；冷启动不自动出声；首版只做页内搜索；不静默跳过坏集；不新增全站抓取、云同步或下载系统重构。这些规则不等待新增后端能力。

工程验证：样本列表顺序 / 完整性、跨系列身份唯一性、音视频时间轴差异、macOS 多窗口行为。默认沿用列表顺序和旧键，媒体时间轴按同一秒数恢复并以有效时长限制；差异较大的样本需显式标记和记录处理决策，不凭空映射。
