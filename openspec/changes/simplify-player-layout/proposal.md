# Proposal

## Why

用户在真机播放页反馈信息和控制过于杂乱，要求简约设计、播放列表使用纯图标，并移除播放器外重复的播放／停止按钮。2026-09-26 已截取当前 iPhone 11 页面：标题与播放器之间有三排辅助内容，下方同时展示连播、双色媒体切换及整块音效档位，视觉层级分散。

## What Changes

- 主页面以单集标题和原生播放器为核心；正常播放／暂停状态不再另占一行，不再外显重复播放／暂停和停止按钮。
- 上一集、播放列表、下一集合并成一排纯图标，保留完整可访问名称、44pt 点击范围和边界禁用。
- 音视频切换改为低对比、紧凑的单色分段控件，去掉橙蓝双色大胶囊。
- 连播、语音降噪、音量放大收进默认折叠的「播放設定」，停止会话收进右上角更多菜单；沿用现有档位与行为。
- 列表数量放在列表面板内；缺失／部分队列、媒体回退、加载、失败和保存错误仍在需要时可见，失败保留明确重试入口。
- iOS 与 macOS 共用同一信息层级，保持既有列表 sheet／popover 和详情往返逻辑。

## Capabilities

### New Capabilities

- `minimal-player-layout`：完整播放页的精简层级、图标操作、按需设置及异常可见性。

### Modified Capabilities

无已同步主规格。复用 `show-player-series-playlist` 的列表与详情合同，本次只调整入口呈现，不复制列表实现；复用 `unify-playback-session` 和 `play-series-in-order` 的会话／队列行为。

## Impact

关联 PRD F1-03／F1-04／F1-06、Q-01～Q-03，以及 AT-01／AT-03／AT-08／AT-11 的控制与状态子断言。范围包括 `PlayerView`、`PlaybackQueueControls`、必要繁体 L10n 和受影响 UI 测试。`AVPlayerContainerView` 已开启原生播放控制；`MiniPlayerView` 已将停止放在更多菜单，可沿用该模式。

非目标：重写播放器、音频封面、修改媒体比例／音频算法／播放状态机／存储格式、改变首页或全局导航。保留当前工作区首页改动，不改部署、依赖、版本和签名。设计稿用于确认布局，不能作为 App 已实现或真机验收证据。
