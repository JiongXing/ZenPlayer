## Context

基线 096307d。分类模型有编号／日期排序但不保留响应 total；系列模型将 rows 原样作为 episodes 与队列。M3 已提供 ScrollViewReader／episode id 定位和文字标记，但未清筛选／定时结束高亮。现有独立 XCTest 可编译生产 ViewModel 并用注入闭包替代 API。

## Goals / Non-Goals

Goals：完整数据与过滤结果分离，预处理字段只在数据／排序变更时做，查询不产生网络／磁盘副作用。Non-Goals：不抓取额外目录，不建磁盘搜索库，不重构播放器／下载，不把页内搜索扩成全站。

## Decisions

- CatalogSearchIndex 保存归一化字段与原顺序。文本去空白、宽度折叠及固定 locale 小写，简繁用源码固定单向表统一为简体；覆盖 PRD 样本及常用佛学字，异体／一对多如 發／髮→发、後／后→后固定收敛。未列字原样保留，明确词典边界。不使用随系统词典漂移的语言转换，也不做模糊匹配。query 每词跨字段 AND；纯数字按实际 episode 数值优先（前导零同值），其他包含命中保序。
- 两个页面 ViewModel 保持原始全量数组、预处理索引、派生可见数组；查询立即更新，无防抖。先测 1000／2000 样本，本地算法达标仍不替代实际输入到画面 P95。分类排序在原完整数据上执行并更新索引；系列队列只在网络数据加载成功时建立，搜索／跳集不注册新快照。
- EpisodeNumberParser 限制 ASCII 数字（宽度折叠后）和成对“第…集”，拒绝符号、小数、负数与溢出，trim 可接受外部／包裹内空白。匹配真实 episode 值，重复返回所有候选，不按 index。SeriesDetailViewModel 的定位方法统一清词／候选并发布带 UUID 的稳定 episode id，重复定位同一集也有反馈。
- 定位输入使用可关闭的 sheet，提交后收起键盘与面板；错误与重复候选在系列列表上方显示，候选选择只定位。视图按定位 UUID 启动可取消 task，布局后滚动、文字及描边突出 2 秒；新请求／离页取消旧 task，不能由旧完成回调清除新高亮。Reduce Motion 不动画。上次收听和历史路由走同一路径。
- 网络 loader 通过闭包注入，默认调用既有 API；测试精确覆盖加载失败／重试／部分内容。URL 离线错误（包括 APIError 包裹）转为明确联网文案。加载请求由调用页面 task 所有，用 UUID 隔离迟到数据／错误及 loading 清理；取消后立即重进不能被旧 loading 拦住。未知或部分 total 都显示已加载范围；零结果和错误分支互斥。

- iPhone 紧凑单集行在辅助字体级别采用纵向字段布局，标题、进度、定位标记、集数、时长、大小和下载动作各自获得可读空间；常规字号沿用原紧凑行。保持相同 PlaybackContext 和下载动作，不为可访问性改变队列或播放行为。

## Risks / Trade-offs

- 固定简繁表存在覆盖边界 → 版本控制字表与等价测试，不宣称所有异体相等。
- 输入与大字体／键盘／滚动时序 → 保留稳定 id、标准控件、44pt 主操作，实际 UI 与辅助功能逐项验；视图定位不能仅靠模型测试关闭任务。
- 前序真机缺口 → 最终 AT-01～26 按子断言汇总，保持 In Verification；设备未就绪不妨碍独立实现和可运行检查。

## Migration Plan

无数据迁移。搜索状态仅在页面内存存在；旧进度键、下载数据、播放快照格式及行为不变。按阶段提交隔离，可审查；不 sync／archive／push／发布。
