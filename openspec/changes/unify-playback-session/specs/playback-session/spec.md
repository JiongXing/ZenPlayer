## Purpose

为跨页面浏览提供同一播放会话，使用户离开控制页面后仍能继续收听，并让暂停、停止、重试、中断恢复与系统控制遵循一致的意图和当前媒体身份，避免重复播放器和过期请求覆盖。

## ADDED Requirements

### Requirement: R1 唯一会话与最后选择
系统 SHALL 在进程内共享一个活动会话。macOS 仅提供一个主窗口，不提供新建第二窗口的入口。所有入口选择同一原始单集键时只显示控制页，不重新准备或改变暂停；选择新目标先保存旧值，仅最后请求可提交媒体和控制信息。

#### Scenario: S1 浏览与重复进入
- **WHEN** 播放或暂停后返回、切 Tab、浏览另一系列、从历史或下载重复打开同集
- **THEN** 复用当前播放器与位置，暂停不自行恢复，没有第二音轨

#### Scenario: S9 macOS 单窗口关闭与重开
- **WHEN** 用户关闭 macOS 主窗口或正常退出 App，再重新启动
- **THEN** 退出前保存进度，重启只显示一个主窗口且不自动播放；用户续听时从保存位置恢复

#### Scenario: S2 快速切换失败
- **WHEN** A 后依次选择 B、C，B 迟到或 C 准备失败
- **THEN** A 进度保留，C 是当前目标；B 不能覆盖，失败不自动恢复 A

### Requirement: R2 一致控制及生命周期
系统 SHALL 在完整页、迷你条与 iOS 系统控制共享标题、状态和位置。停止保存后释放媒体与系统命令并隐藏迷你条；页面消失／窗口失焦不停止，冷启动不出声。音视频切换保留即时位置和暂停意图，恢复失败不覆盖进度。

#### Scenario: S3 控制与停止
- **WHEN** 从不同控制面暂停／恢复／停止，再冷启动
- **THEN** 控制同一媒体，停止后媒体和锁屏控制清理，历史仍保留，冷启动不自动播放

#### Scenario: S4 全屏及媒体切换
- **WHEN** PiP／全屏往返、关闭完整页、窗口失焦或暂停切换音视频
- **THEN** 不创建另一会话；切源保持当下位置和意图，失败可重试且不写入初始 0

### Requirement: R3 中断与自然结束意图
系统 SHALL 仅在中断前正在播放、系统允许且期间未手动暂停时恢复；拔耳机视作暂停。自然结束在无队列阶段保持结束状态，不循环，用户可主动重听。

#### Scenario: S5 中断期间暂停
- **WHEN** 播放被中断后用户暂停，再收到允许恢复通知
- **THEN** 保持暂停；原本暂停或耳机断开同样不自动播放

#### Scenario: S6 自然结束
- **WHEN** 当前媒体自然结束
- **THEN** 保留 completed 与结束状态，不自动重复，重听从 0 准备且实际推进后更新进度

### Requirement: R4 状态反馈与无进展超时
系统 SHALL 立即显示选择，超过 300 毫秒显示加载；准备或缓冲连续 30 秒无有效进展进入可重试失败，用户暂停不计时。迷你条显示完整可访问标题与截断视觉标题、状态、44pt 主控和停止菜单；完整页／全屏隐藏重复迷你条。

#### Scenario: S7 超时和重试
- **WHEN** 媒体准备或缓冲 30 秒无有效进展，或报告加载失败
- **THEN** 完整页与迷你条显示同一失败目标和重试动作，保留旧进度，不静默跳课

#### Scenario: S8 安全区与辅助功能
- **WHEN** 在根页、详情页或完整控制页，使用大字体和 VoiceOver
- **THEN** 迷你条在适用的底部安全区可操作且不遮列表末行，完整页不重复，长标题仍有完整可访问名称

## 2026-09-26 验证范围调整

用户要求“测试用例不必太严苛，极端情况不必考虑，核心保证主流程可用即可”。阶段验收采用现有确定性测试和实际 UI 主流程证据；不再将 VoiceOver 全流程、所有字体／窗口组合、精确动画时长或重复压力执行作为本轮工程任务完成条件。相关产品行为仍保留，实现走读与未运行的设备／辅助功能验证分别登记，不写成通过。真实 iPhone 后台／锁屏／PiP 等核心平台能力继续由 M1／M2 及 M4 汇总追踪；本阶段展示完成不关闭其缺口，也不等于发布验收。
