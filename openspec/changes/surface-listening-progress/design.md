## Context

基线 81dc155，M2 已交付真实 PlayerViewModel 隔离集成测试。首页 Group 按分类状态整页切换，系列行只显示元信息。M0 store 的长期 records、lastListenedAt 和 state 是唯一权威数据；M2 的轻量引用与快照恢复可直接复用。

## Goals / Non-Goals

Goals：只读派生候选和状态，播放动作使用统一会话；定位用稳定 id，不改变列表或队列。Non-Goals：不引入第二套历史／位置存储，不新增网络抓取，不提前实现搜索，不把 UI 编译当交互验收。

## Decisions

- ResumeCandidatePolicy 为纯规则，使用全部长期记录，不使用 recentRecords 的 10 条截断。有效实际收听依据 lastListenedAt；零位置且未开始的旧记录不是“其他未完成”候选。同时间以原键稳定排序。最近完成集仅看快照紧邻项，不跨过完成集找更远项。
- HomeResumeViewModel 仅异步获取最近完成集的本地快照；以原键／状态／快照引用作为刷新身份，进度 tick 不重读整个快照。活动会话优先即时派生，异步结果按请求身份丢弃；分类网络状态不作为输入。
- HomeView 始终渲染本地卡片及分类独立状态。准备时禁用重复按钮；活动会话按意图播放／暂停，历史点击走明确续听方法，同集失败或结束也能重试／重听，不能被 M1 同键幂等规则吞掉。
- 单集进度用独立轻量文字组件读取 store，父列表保持原稳定身份；首页总时长未知不显示百分比。SeriesDetailView 用 ScrollViewReader 和目标 episode.id；按 reduceMotion 决定是否动画，高亮有“目前定位”文字（历史入口可能定位较早的单集，不能误标为最近收听）。定位只改本页状态。
- 增加轻量 SeriesDestination 值路由（id／标题／详情 URL／目标单集），保留已有 SeriesItem 值路由；历史引用足够构造目的地，不填造假的完整 SeriesItem。M4 清筛选定位复用同一目标入口。

## Risks / Trade-offs

- 下一集快照迟到／缺失 → 先保留有效本地候选、按刷新身份更新，不发网络请求／不自动播放。
- SwiftUI 滚动与动态字体 → 稳定 id、显式用户定位、缩短动画偏好；实际 UI 另验，不能由模型测试声称通过。
- 旧关联缺失／离线目录无法加载 → 历史位置仍保留；系列页显示加载错误，不伪造已定位。M4 补筛选清除与目标不可见说明。

## Migration Plan

不迁移或重写进度，不改原键、快照格式和下载清理边界。保留 M0～M2 设备缺口；M3 只增加查询／展示和定位路由。
