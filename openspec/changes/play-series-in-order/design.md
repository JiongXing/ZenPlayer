## Context

基线 b3e35b8，工作区干净，M1 在 In Verification。SeriesDetailViewModel 直接使用 rows，totalCount 可表示是否完整；PlaybackContext 尚无系列关联，PlaybackProgress 预留了可选系列字段。M1 媒体 token 和进度门可复用。见 proposal.md。

## Goals / Non-Goals

Goals：让纯队列模型可隔离测试、快照 I/O 不阻塞已可播放单集、旧记录继续可读。Non-Goals：不做远端补队列／分页抓取、目录离线缓存、自定义队列、首页卡或搜索；快照只是已选择系列的播放上下文。

## Decisions

- QueueSnapshot 使用不可变版本 ID、系列元信息、原始服务器、rows 和完整性；PlaybackContext 只增加可选轻量系列引用，进度不嵌入全列表。系列加载时构造一次快照并只缓存内存，传给未筛选行；选择播放后才持久化，不因浏览缓存全部目录。当前索引保存在轻量引用及会话队列中，并以本集原键重新核实；不在每个 tick 创建／写快照。避免复制整个队列进入每条进度。
- QueueSnapshotStore 在 Application Support 的独立目录原子写每版本文件，后台串行 I/O，内存保留写失败快照并展示非阻断提示。已落盘的不可变版本不重复写，旧数据无需迁移。历史／下载用 context 引用优先，其次已有进度引用，再以原始 legacyKey 查本地快照；跨系列匹配歧义时不猜测队列。
- 纯 PlaybackQueueState 持有快照和索引、队列修订及有效媒体 token，唯一消费自然结束；App 会话负责先记 completed 再执行新选择。队列边界返回 nil，不生成虚构集数。换媒体保留快照；重复点同集不换队列／不唤醒暂停。
- 队列恢复异步且带选择版本；播放准备并行开始，迟到恢复只能关联原目标，不得改索引到其他媒体。结束前未恢复则按单集结束，不事后自动启动。UI 明确恢复／单集／已加载范围。
- 媒体选择提取纯策略，输入支持类型、本地文件可用性和已知离线状态；未知网络先尝试，确认离线时才优先本地另一类型。系统 Network path 只提供网络状态，不做网络探测或自动反复重试。降噪与音量仍由同一模型持有。
- UserDefaults 只存连播布尔偏好（可注入隔离 suite）；首装缺键为 true。UI 开关不操作 player。上一／下一集明确 play，新集自己的 M0 resumePosition 决定位置。

- 实际会话集成测试注入隔离进度／快照／UserDefaults、本地文件查找、网络状态及音频处理控制面；生产 convenience init 仍绑定原 DownloadManager／RNNoise。测试用真实 AVPlayer 临时静音 WAV，延迟处理器只控制准备顺序，不复制会话实现；覆盖实际切集、进度和迟到回调。

## Risks / Trade-offs

- 快照缺损／写失败 → 单集仍可播放且进度完全独立，保留错误提示；不删除源进度或未知版本文件。
- 旧键跨系列歧义 → 显式系列引用优先，缺引用且匹配多个系列时不自动关联；验证原始服务器字符串和重复单集键。
- 回调／网络状态竞态 → 选择修订、媒体身份、队列修订三者隔离；纯模型测试与真实设备验证分别记录。
- AT-09 搜索集成在 M4 重验；AT-12 锁屏／PiP 自动换集需真实设备。M0／M1 缺口不因此关闭。

## Migration Plan

新增可选字段及独立快照目录，旧 JSON 解码缺字段继续有效；不改 legacyKey。删除下载不删除快照／进度。回退实现可忽略新字段，保留既有文件。无主规格同步／归档／发布动作。
